# Dashboard Guidelines

When the application requirement includes a dashboard view, follow these design patterns to provide a clear summary of data and metrics.

## Guidelines

- Provide an intuitive overview of key entities, metrics, and system statuses.
- Use summary cards with key counts, aggregate metrics, and status breakdowns.
- Incorporate clear visual charts (e.g., bar charts, progress bars, or trend graphs) to show data distribution.
- Ensure pending or unprocessed items are clearly indicated (e.g., "Pending", "Not assessed").
- Provide interactive controls (filtering, sorting, or data refresh) where appropriate.
- Maintain consistency with the primary UI design system (`ui-design.md`).
